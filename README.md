# cli-greeter

A minimal Node.js CLI greeter.

## Usage

### No arguments

```
$ node greet.js
Hello, world!
```

### One name

```
$ node greet.js Alice
Hello, Alice!
```

### Multiple names

```
$ node greet.js Alice Bob
Hello, Alice, Bob!
```

### Help

```
$ node greet.js --help
Usage: node greet.js [name...]
```
