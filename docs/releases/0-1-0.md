# e2e gate check 0.1.0 (0.1.0)

## factorlib 0.1.0

The first release of **factorlib**, a small typed Python library for prime factorization, built test-first: a red test proving the packaging works end-to-end, a trial-division `prime_factors` implementation to make it pass, and a terminal-friendly CLI on top. Install it, `import factorlib` in your own code, or run `factorlib <ints...>` straight from your shell.

### Highlights
- `prime_factors(n: int) -> list[int]` -- ascending prime factorization by trial division, e.g. `prime_factors(12) == [2, 2, 3]`.
- Clear input contract: `prime_factors(1) == []`, any `n <= 0` raises `ValueError` naming the offending value, and non-int input raises `TypeError`.
- New `factorlib` CLI: `factorlib 12 18 7` prints one `<n>: <factors...>` line per argument (Unix-`factor`-style) and exits with status 1 if any argument was invalid, 0 otherwise.
- Typed package (`py.typed` marker) with an src-layout, a setuptools build backend, and a full pytest suite covering composite, prime, prime-square, and edge-case inputs.

No breaking changes -- this is the initial release.

## Rollback

factorlib 0.1.0 is the first release, so there is no prior version to fall back to -- rollback here means safely correcting a bad v0.1.0, not reverting to an earlier one. Never delete the v0.1.0 git tag or the GitHub Release; deleting remote state is forbidden. Instead: (1) Revert the offending commit(s) on main with a new commit (`git revert <sha>`), never a history rewrite or force-push. (2) Re-run this same runbook with VERSION bumped to 0.1.1 to cut a corrective patch release once the revert is tested and green. (3) Edit (do not delete) the v0.1.0 GitHub Release description to add a visible notice of the known issue and point users at v0.1.1. (4) If the 0.1.0 dist/ artifacts were pushed to a package index (e.g. PyPI), use that index's non-destructive 'yank' feature to hide 0.1.0 from dependency resolution without deleting the file, and publish 0.1.1 as the fix. (5) Advise anyone who already installed 0.1.0 to upgrade with `pip install --upgrade factorlib`.
