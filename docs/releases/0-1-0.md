# e2e gate check 0.1.0

This is the first release of **factorlib**, a small Python library and command-line tool for prime factorization by trial division. It ships the core `prime_factors` API with fully specified boundary behavior, a `factorlib` console script that wraps it for everyday command-line use, and a test suite covering all of the function's edge cases.

## Highlights
- New `prime_factors(n: int) -> list[int]` API: returns the ascending, multiplicity-preserving list of prime factors of `n`, computed by trial division.
- Well-defined boundaries: `ValueError` for `n <= 0` (message names the value), `[]` for `n == 1`, `TypeError` for non-int input.
- New `factorlib` command-line tool: run `factorlib 12 18 7` to print each integer's factorization, one line per integer.
- Fail-fast CLI semantics: on an invalid integer, everything printed so far stays printed, the error goes to stderr, and the process exits 1 without touching later integers.
- Installable as a standard src-layout package: `pip install .` (Python >=3.12 required).
- Full boundary-case test coverage for `prime_factors` (12, 97, 49, 1, 0, negative, non-int).

# Changelog

## [0.1.0] - 2026-08-11

### Added
- `factorlib` package (src-layout, setuptools `build_meta` backend, Python >=3.12) with a `prime_factors(n: int) -> list[int]` public API computed by trial division (divide out 2, then odd divisors up to sqrt(n)).
- Boundary behavior for `prime_factors`: raises `ValueError` (naming the offending value) for `n <= 0`, returns `[]` for `n == 1`, returns the ascending multiset of prime factors for `n >= 2`, and raises `TypeError` for non-`int` input.
- `factorlib` console-script CLI (`factorlib N1 [N2 ...]`) that prints one `N: f1 f2 f3` line per integer, exits 0 on success, and on the first failing integer prints the already-succeeded lines, writes the error to stderr, and exits 1 without processing further integers.
- Test suite (`tests/test_factor.py`) covering all seven `prime_factors` boundary cases: 12, 97, 49, 1, 0, a negative integer, and a non-int argument.

## Rollback

This is the initial 0.1.0 release, so there is no prior version to revert to. If a defect is found after publishing:
1. Do not delete or unpublish the v0.1.0 tag, GitHub release, or its artifacts (remote deletions are forbidden) -- instead edit the GitHub release description to add a visible warning that 0.1.0 has a known issue and point readers at the fix version once it exists.
2. Note in the release/README that consumers should not newly install factorlib==0.1.0 until a fixed version ships.
3. Fix the defect, bump to 0.1.1, and re-run the standard release steps to ship a fix-forward patch release -- never force-push or rewrite the v0.1.0 tag.
4. Existing installs should upgrade with `pip install --upgrade factorlib` once the patched version is published.
