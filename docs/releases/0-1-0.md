# e2e standup poster 0.1.0 (0.1.0)

## e2e standup poster v0.1.0

The first release of the standup card: a tiny, dependency-light single-page app that renders one clean card for your daily standup — today's date, and what you did yesterday, what you're doing today, and what's blocking you, all at a glance.

### Highlights
- Live date heading, computed at render time — never a stale, hardcoded date.
- Yesterday / Today / Blockers, each rendered as a simple bulleted list.
- Blockers shows a clear, muted "none" when there's nothing blocking you, instead of leaving the section looking broken or empty.
- Zero backend, zero fetch — all content comes from one hardcoded data object, so the app is trivial to run and reason about.
- Built with Vite + React + TypeScript; styled with CSS Modules.
- `npm ci && npm run build` produces a static `dist/` folder you can host anywhere.

Run once, after checking out the CONFIRMED release commit, to perform the release.

## Rollback

This is the first release (PREVIOUS: None), so there is no prior version to fall back to. If v0.1.0 needs to be pulled back: (1) stop pointing any hosting/CDN/consumer at the v0.1.0 dist artifact or tag; (2) do NOT delete the `v0.1.0` git tag or GitHub release — deleting remote state is prohibited — instead mark it clearly as rolled back in place, e.g. `gh release edit v0.1.0 --prerelease --notes "Rolled back — see v0.1.1"`; (3) cut a corrected release (e.g. v0.1.1) from a fixed commit rather than retagging or force-pushing over v0.1.0. Because this app is a static, backend-free SPA with no migrations, rollback is purely a matter of which built `dist/` a host serves — no data state to reconcile.
