# e2e quote page v0.1.0

First release of the e2e quote page: a single-page, fully static Astro site that shows one quote, chosen once at build time, centered on a dark page with the author printed beneath it in smaller, dimmer type. The build makes zero runtime network requests -- no external fonts, scripts, or analytics -- and ships a print stylesheet so the page comes out legibly on paper.

## Highlights
- Static, build-time quote selection: the quote is picked inside `index.astro`'s frontmatter during `astro build`, not in the browser.
- Reproducible picks: `pick<T>(quotes, seed)` in `src/lib/pick.ts` derives the choice deterministically from a seed, so rebuilding the same commit always renders the same quote.
- Zero runtime network requests: dark background, system font stack only, no `@font-face`, CDN fonts, or external scripts.
- Print-friendly: `src/styles/print.css` renders black-on-white 12pt serif on paper without hiding any content, and only applies when printing.
- README documents `npm ci && npm run build` and how to add new quotes.
