# e2e prime tester 0.1.0 (0.1.0)

## e2e prime tester 0.1.0

This is the **initial release** of the `prime_tester` console application — a self-contained, dependency-free C++17 utility that determines whether integer values are prime numbers.

The application accepts input either as command-line arguments (`./prime_tester 17 42 99`) or from stdin (one token per line), prints `<n> is prime` or `<n> is not prime` for each value, reports non-integer tokens to stderr, and exits with status 1 if any invalid token was encountered. The implementation uses a trial-division algorithm with the 6k±1 optimisation for efficiency. The project is built with CMake (minimum version 3.16) and requires no third-party dependencies.

### Highlights
- New `prime_tester` executable built via `cmake -B build && cmake --build build`
- Dual-mode input: command-line arguments **or** stdin line-by-line
- Clean error reporting: invalid tokens go to stderr; process exits 1 on any error
- 6k±1 trial-division algorithm — correct and efficient for the reference use-case
- Zero external dependencies; C++17 only

### Added
- `CMakeLists.txt`: CMake build definition at repository root targeting C++17, producing the `prime_tester` executable from `src/main.cpp` and `src/prime.cpp`.
- `src/prime.h`: Public header declaring `bool is_prime(long long n)` with include guard.
- `src/prime.cpp`: Implementation of `is_prime` using trial division up to √n with 6k±1 optimisation; handles edge cases (n < 2, n = 2, n = 3, even n > 2).
- `src/main.cpp`: Entry-point supporting argument mode (test each `argv[1..argc-1]`) and stdin mode (read one token per line until EOF); outputs `<n> is prime` / `<n> is not prime` to stdout; writes `not a number: <token>` to stderr for invalid tokens; exits with status 1 if any invalid token was seen.
