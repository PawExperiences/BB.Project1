# e2e unit converter 0.1.0 (0.1.0)

## e2e unit converter 0.1.0

The first release of `units` - a small, dependency-free Python 3.12+ library that converts values between everyday length units and between mass units. Install it and call one function, `convert(value, frm, to)`, to get a precise, unrounded result; ask for something that doesn't make sense (mixing a length and a mass, or an unknown unit) and it tells you exactly what went wrong instead of guessing.

### Highlights
- Single public entry point: `from units import convert`.
- Conversions run through per-dimension factor lookup tables (`LENGTH_FACTORS` for length, `MASS_FACTORS` for mass) rather than a function per unit pair - e.g. `convert(1000, "m", "km") == 1.0`, `convert(1, "kg", "g") == 1000.0`.
- Mixing dimensions (e.g. a length unit to a mass unit) raises `ValueError` naming both units instead of returning a nonsense number.
- An unsupported unit string raises `KeyError` naming the offending unit.
- No implicit rounding, truncation, or formatting - you always get the raw computed float back.
- Full pytest coverage and a README unit reference table with worked examples.

### Install
From the wheel attached to this release:
```
pip install units-0.1.0-py3-none-any.whl
```
Or from source:
```
pip install .
```

See `README.md` for the complete list of supported units, grouped by dimension, and additional worked examples.

> **Release-runbook note - resolve and remove before publishing:** the two bundled tasks behind this release specify different supported-unit sets. ### Added
- Initial release of `units`, a dependency-free Python 3.12+ library for converting values between length units and between mass units.
- Public API: `from units import convert` - `convert(value: float, frm: str, to: str) -> float` converts within a dimension with no rounding applied. Confirmed against both candidate unit specs: `convert(1000, "m", "km") == 1.0`, `convert(1, "kg", "g") == 1000.0`, `convert(1, "cm", "mm") == 10.0`.
- `convert()` raises `ValueError` naming both units when `frm` and `to` belong to different dimensions (e.g. a length unit and a mass unit), and raises `KeyError` naming the unit when `frm` or `to` is not a supported unit string.
- `src/units/tables.py` adds the `LENGTH_FACTORS` and `MASS_FACTORS` lookup tables (factor to the dimension's base unit - metres for length, grams for mass); `src/units/__init__.py` imports and re-exports both rather than duplicating the values.
- `tests/test_convert.py` adds pytest coverage for same-dimension conversion in both directions, cross-dimension rejection, and unrecognized-unit rejection.
- `README.md` documents every supported unit grouped by dimension, with three worked conversion examples.

### Docs
- `README.md`: added the package overview, install instructions, and the full unit reference table.

Per protected-remote-state rules, never delete or force-update the v0.1.0 tag, the GitHub release, or commit history.
