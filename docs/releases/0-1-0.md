## Release steps

1. [manual] Update CI configuration - Ensure that the CI configuration in `.github/workflows/build.yml` reflects the latest changes that correct build issues.
2. [automated] Run CI build - Run the following command to confirm that the CI build passes: `git push`.
3. [automated] Tag the release - Run the command `git tag -a v0.1.0 -m 'Release version 0.1.0'` and push the tag with `git push origin v0.1.0`.
4. [manual] Publish Release Notes - Copy the content of `docs/releases/0-1-0.md` and publish it on the GitHub release page for version 0.1.0.
