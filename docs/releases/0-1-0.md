# e2e quote page v0.1.0

First release of the e2e quote page: a minimal, dependency-light Astro static site that renders one quote -- picked deterministically at build time from a fixed set of five -- centered on a dark page in the system font stack, with a dedicated print stylesheet and no runtime network requests.

## Highlights
- Buildable Astro static site (`npm ci && npm run build`) producing `dist/index.html`.
- Deterministic, seedable quote selection at build time via `src/lib/pick.ts` -- no client-side randomness, no runtime fetch.
- Dark, centered layout with the author rendered smaller and dimmer beneath the quote, system font stack only.
- Print stylesheet (`src/styles/print.css`): black-on-white, 12pt serif, nothing hidden when printed.
- README documents how to add a quote and how to build.

## Rollback

This release has no server, database, or persisted state -- rollback only concerns the published artifact.
1. Do not delete the v0.1.0 tag or GitHub release (remote deletions are forbidden); if it must be pulled from prominence, edit the release notes to mark it superseded/known-broken instead.
